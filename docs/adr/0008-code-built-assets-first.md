# 0008. Code-built assets first, asset packs later

- **Status:** accepted
- **Date:** 2026-11-14
- **Decided by:** the person

## Context

The first goal is to match the Cold Containment style previews. Agents can
edit scripts, not hand-made art files.

## Decision

Models are built by Blender Python scripts in `tools/assets/` that export
`.glb` into `assets/`; sounds are generated by scripts. The script is the
source; its output is never hand-edited. Asset packs (CC0 first, CC-BY with
credit) come later to raise quality, each credited in `docs/CREDITS.md`.

## Consequences

- Change a model by changing its script, then run the Assets CI checks.
- No "non-commercial" or "no AI" licences.
- No Git LFS for now.
